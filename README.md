A full‑stack, database‑driven IT Service Desk system built using PHP, SQL, HTML, and CSS. The application enables staff to raise technical support requests, track ticket progress, communicate with IT teams, and access a repository of user guides. An administrative portal provides IT staff with tools to manage workloads, assign tickets, and maintain documentation.

Project Overview
This project was designed to streamline internal IT support processes by providing a centralised platform for ticket management and communication. The system supports both end‑users and IT administrators through separate interfaces with role‑based access control.

The application was developed using a LAMP‑style architecture (XAMPP, PHP, SQL) and demonstrates full‑stack development skills including backend logic, database design, and UI implementation.

Key Features
For Staff (End Users)
Secure login and session management

Submit new support tickets with issue details

View ticket status and full communication history

Receive automated email notifications for updates

Access a file repository of user guides and documentation

For IT Staff (Admin Portal)
Role‑based authentication and access control

Assign, update, and manage support tickets

Communicate with staff through ticket‑level messaging

Upload and maintain user guides in the repository

View and manage ticket workloads across the team

Technologies Used
PHP — backend logic and server‑side processing

SQL / SQLite — database design and CRUD operations

HTML & CSS — UI layout and styling

JSON — structured data handling

XAMPP / PHPMyAdmin — local development environment
